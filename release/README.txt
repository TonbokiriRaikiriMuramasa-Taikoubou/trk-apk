trk! Android版 — 開発ソースのご案内

これはtrk 1.1.4（trk214）を土台としたAndroid版の開発ソースです。
開発用debug APKはCIでビルドできましたが、Android実機では未検証です。

 docs/apk-development.md を参照してください。
