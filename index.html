🛟 緊急復旧 / Emergency Recovery
画面が真っ暗・触れなくなった時はURLに ?safe=1 や ?reset=tv を付けて開き直すと復旧できます。
If the screen becomes unusable, add ?safe=1 or ?reset=tv to the URL and reload.

Android版：右下の画面向きボタンを10秒長押しするとセーフモードを開けます。

URLコマンド一覧
  • ?safe=1 / #safe — セーフモード：映像OFF・ぼかし0・TV初期化
  • ?reset=tv / ?reset=video — 映像・TV・ぼかし・TVスキンをデフォルトに（ノーツは保持）
  • ?reset=audio — 音量・SEをデフォルトに
  • ?reset=notes — ノーツ色・形をデフォルトに
  • ?reset=lite — 🪶 軽量化の設定をデフォルトに
  • ?reset=all / ?factory — 全設定を工場出荷状態に
  • ?export=notes / ?export=all — 設定をJSONでダウンロード
  • コンソール: trkReset('tv'), trkExport('notes')

⚙ 設定

初期オフ。オンにすると全画面中は画像全体を縦横比を保って表示し、拡大・縮小操作を無効にします。見開きは左右それぞれ、縦読みは1枚ずつ画面に収めます。全画面を閉じると元の拡大率に戻ります。

チェックを外しても、上の「本棚を表示」からいつでも戻せます。

特殊フィルタ（読書）

読書面（画像と文章）だけに CSS filter を当てます。全画面フィットや拡大率とは独立で、本棚やメニューは変わりません。初期値は 100% / 100% / なし。

オフ（初期値）では、倍率に関係なく、はみ出した画像の上端／下端へ移動します。端で押し直すと前／次のページを続きの端から開き、本の端では全画面を終了して本棚へ戻ります（最後のページで閉じるかは下の設定で変更できます）。オンでは直接ページを送ります。縦読み・テキスト・画面に収まる画像は従来どおりです。

画像の端へ移動する操作で、最後のページの下端からもう一度PageDownを押すと、本を閉じて全画面を終了します（初期オン）。オフなら下端で止まります。先頭ページでのPageUp・中クリックの設定は変更しません。

左クリックで次のページ、右クリックで前のページ。画像の本のときだけ働きます（ページ上の位置は選びません）。

トラックボールや左利きの人向け。上の「左右クリックでページを送る」がオンのときだけ選べます。

マウスの中クリック

画像の本のときだけ働きます（ブラウザの自動スクロールは止めます）。
