# trk! Android版 仕様変更まとめ

記録日：2026-10-29（日本時間）

## 0. 読み方と基準

- 基準はGitHub上流 `trk` のコミット `2b3383dc5051eb561213a7d4f875307a9e02b975`（trk214／1.1.4）。Google Drive上の1.1.4 ZIPとはバイト比較していません。

- Android版の仮アプリIDは `com.trk.agrg`、minSdk 24、target／compileSdk 36。WebViewとCapacitor 8のシェルとして、上流の音楽・動画プレイヤー、リズムゲーム、書斎などを引き継ぎます。Android向けの動作は機能ごとに確認が必要です。
- Android画面・設定の詳細は `docs/apk-development.md`、開発状態は `docs/HANDOFF.md`、実機試験は `docs/ANDROID-DEVICE-CHECKS.md`、Media3案は `docs/media3-plan.md` を参照してください。

## 1. 上流trkからの主な仕様変更・追加

### 画面と再生導線

| 項目 | Android版の現状 | 状態・注意 |
| --- | --- | --- |
| 基本ナビ | 下部に **ライブラリ／エフェクト／再生／書斎／ゲーム**。曲・動画・プレイリストはライブラリに集約。 | 画面遷移のJSテストあり。端末の小画面・横向きは未検証。 |
| ゲーム準備 | ゲーム準備・スペクトラムを通常の選曲画面から格納。再生中にゲームモードへ進み、選択曲から譜面生成・プレイする導線を仮置き。 | プレイヤー退出時の再生は既存設定に従う。5モードと遷移は実機未検証。 |
| エフェクト | 再生を維持してエフェクトへ移り、プリセット、5帯域EQ、映像色調を操作。プレイヤーへ戻ると映像プレビューを戻す。詳細設定はプレイヤーを閉じて開く。 | Web Audio・映像・ゲームとの実動作と同期は実機未検証。 |
| 取り込み | 「コンテンツを追加」に既存のファイル／フォルダ／パック等の入口を畳む。再接続・再スキャンは必要時に表示。 | 削除していない。選択UI・フォルダの永続アクセス・再接続はAndroidで未検証。SAF／MediaStoreは未実装。 |
| シンセ | 「シンセモードを使用する」を追加し、新規時と音声設定初期化時はOFF。既存保存設定は尊重。 | 有効時は既存の操作からシンセを開く。 |
| 設定パネル | 初回は閉じ、手動の開閉状態を端末に保存。検索による一時開閉は保存しない。 | 開閉状態は設定バックアップには含まれず、全設定リセットで削除。 |
| trk's playlist | 起動時に一括自動作成せず、設定のカタログから必要なプレイリストを個別追加。編集済みリストは上書きしない。 | カタログは音源を配布しない。内蔵デモを除き音源は別途必要。 |
| 画面の戻る | Android Backで全画面・確認・書斎・設定・プレイヤー・ゲームを段階的に閉じ、最後に終了確認。未知のモーダルは安全側で消費。 | エミュレーターでは初回案内のBackのみ確認。予測型戻る・他の階層は実機未検証。 |

### 向き・緊急復帰

- 通常の向きは端末設定に従う。右下のボタンは現在の向きの一時固定／解除に使用し、固定状態は保存しない。ゲーム中・一時停止・結果画面、モーダルや書斎では非表示。
- 同じボタンの**10秒長押し**で緊急復帰の確認を出す。長押しがWebViewのジェスチャーで中断されにくい設定を試みているが、OS割り込みや実際のタッチを含め実機未検証。ゲーム中に画面が見えなくなった場合の戻る経由の復帰も確認が必要。
- ゲーム画面の最終的な向きは実機を見て決める。

### アンテナ・画中絵・イヤホン

- タイトル右上のアンテナで、裏画面でも再生継続を**試みる**／裏画面では一時停止する方針を切り替える。WebViewはOS・省電力・画面ロックで停止することがあり、継続を保証しない。ゲーム中は記録保護を優先する。
- 自動画中絵（PiP）はプレイヤー内の設定で初期OFF。ON時は動画のみが既定で、音楽も含める選択肢をONにすると曲名とアイコンを表示。ゲーム中はPiP対象外。非対応・拒否・移行失敗時はアンテナ設定に戻る設計。
- 動画のPiP枠は動画の縦横比をAndroidの範囲（1:2.39〜2.39:1）に丸める。音楽や寸法不明は16:9。専用のPiP再生／停止ボタンは未実装。**PiP遷移・実際の縦横動画表示は未検証。**
- Web Media Sessionのplay/pauseの重複命令を冪等にし、Activity表示中のハードウェア音量キーをメディア音量に関連付けた。Media3サービス・ネイティブMediaSession・Audio Focusの統合は未実装。通知・ロック画面・Bluetoothを通る操作は未検証。
- Shokz OpenRun Pro 2は音量＋／－と多機能ボタン1回／2回／3回（再生・一時停止／次／前）を受け入れ目標として記録。現状対応済みとは扱わない。
- 「無音のまま再生を進める」は❓謎設定の候補として保留。MIDIとWeb Audioを含む音声経路やミュート復帰を検討するまで実装しない。

### 端末データ・安全性

- AndroidではService Workerを新規登録しない。旧同スコープのWorkerとバージョン別シェルキャッシュだけを整理し、共有インボックスなど利用者データは対象にしない。Web／PWA版のService Workerは維持。
- `allowBackup=false` に加え、Android 12以降のクラウド／端末間転送の対象ドメインを除外するルールを設定。OS・メーカー固有ツールの挙動は実機未検証。機種変更前は必要なデータを明示的にバックアップする。ユーザーが書き出したバックアップファイルは別扱い。
- FileProvider外部領域はアプリ固有Picturesに限定し、署名鍵をGit管理から除外。`INTERNET` 権限は残す。OS共有インテント受信、ネイティブSAF・MediaStoreは未実装。

### 素材・ライセンス

- Lat式ミクのモデル・テクスチャは現行ソースとAPK用生成物に同梱せず、[作者の配布先](https://bowlroll.net/file/30199)を案内する。ユーザーの持ち込みと内蔵65種のモーションは維持。現行の配布モデルとの互換性やAndroid描画は未検証。旧Git履歴・古いDrive配布物にはモデルが残る。
- Lat式を除いても初音ミク二次創作や東方素材等は残る。利用・改変・再配布条件、クレジット、NOTICE、ストア配布条件を素材・依存物ごとに確認する。無料または非営利というだけで無条件に利用可能とは判断しない。
- 使用条件を満たすフリーな素材・依存物は前向きに検討する。開発作業・CI等の承認範囲は `docs/decisions/0002-development-authorization.md` を参照。

## 3. 確認済みと未確認

- JS等の `npm run check` は **711件成功、37スイート**。`npm run cap:sync`、差分の空白チェックも成功。JSテストはjsdom／モックで、Android音声や物理画面の確認ではない。
- GitHub Actionsの[debugビルド](https://github.com/TonbokiriRaikiriMuramasa-Taikoubou/trk-apk/actions/runs/40750870972)（`0d24a96`）でJavaを含むビルド成功、debug APKを期間限定で保存。Gradleのdebug鍵による署名であり正式配布版ではない。後続 `9c53d5c` は検証結果の文書更新のみ。
- Android API 35エミュレーターの[検査](https://github.com/TonbokiriRaikiriMuramasa-Taikoubou/trk-apk/actions/runs/40750871895)（`0d24a96`）では初回起動、Backキーで初回案内を閉じる操作、向き固定の橋渡し、PiP比率の計算・橋渡しを確認。JSクリックを使い、PiP移行・動画表示は確認していない。
- Android**実機、物理タッチや10秒長押し、音声・動画・ゲーム、PiP、D2D、Shokz／Bluetooth、通知、画面ロック**は未検証。M1の実機チェックは未完了。

## 4. 今後の段階・未決事項

1. **M1 実機スモーク**：対象端末・Android版・APKのコミットを記録し、取り込み、再生、FX、5モード、戻る、向き、アンテナ、PiP、ロック等を確認。問題を再現・記録する。
2. **M2 安定化**：実機で見つかった問題、入力や遅延の実測に基づく修正。未知のモーダルのBackは安全なキャンセル方法が特定できるまで任意のボタンを押さない。
3. **M3 Media3**：WebView再生とFXを維持しながらMediaSessionService／SimpleBasePlayerで命令を中継する案をまず検討。WebView停止時の継続は保証されない。不足が実測された場合のみFXなし聴取専用のExoPlayerを検討し、全面移行しない。採用時はApache-2.0と各依存物の条件を確認。
4. **M4 取り込み**：SAF・共有インテント・永続URI、長い動画の範囲アクセスとシーク、権限喪失時の復帰を検討。
5. **M5 配布**：正式署名・鍵の管理、GPLの対応ソース・権利表記、GitHub／Play等の配布先と条件を検討。アプリID、東方なしビルド、プロセス終了後の自動再開は未決。

実機の結果はコミット・機種・Android版を添えて別途記録し、本書の未検証項目を推測で埋めないでください。
