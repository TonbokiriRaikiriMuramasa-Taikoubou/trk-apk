# ✔ trk! 公認パックの手順

公認パックは、**作曲家さん・譜面作者さんの本人確認と、曲の権利の確認が済んだ曲パック**です。
trk! は、パックのファイル全体の指紋（SHA-256）を `verified.json` と照らし合わせて ✔ を付けます。

## 流れ
1. 作者さんが、trk! の「📦 この曲を曲パックにする」で `.stpack` を作ります。
   - 譜面作者の名前（必須）・BPM・作者のことば（任意、Xの無料枠と同じ280まで）を入れます。
2. 作者さんが、自分の配布ページ（BOOTH・Google Drive・GitHub Releases など）にパックを置きます。**曲はこのリポジトリに入れません。**
3. オーナーが本人確認をします（下のチェックリスト）。
4. オーナーが、そのパックを trk! に入れ、設定画面のパック一覧の「📋 公認リスト用にコピー」を押します。
5. コピーした行を `verified.json` の `packs` に貼り、`creators` の id を入れて公開します。

> ⚠ 作者さんがパックを作り直すと、指紋が変わります。そのたびに 4〜5 をやり直してください。
> 作者のことばだけを直したい場合は、`verified.json` の `comment` を書き換えれば、パックを作り直さずに済みます。

## verified.json の形

```json
{
  "format": "trk-verified",
  "version": 1,
  "creators": [
    { "id": "example-p", "name": "例のP", "x": "example_p", "url": "https://example.com", "roles": ["composer", "charter"] }
  ],
  "packs": [
    {
      "sha256": "64文字の指紋",
      "creators": ["example-p"],
      "title": "曲名",
      "comment": "作者のことば（280まで。全角・絵文字は2として数えます）",
      "notice": "表示が必要なクレジット（任意）",
      "addedAt": "2027-01-01"
    }
  ]
}
```

`roles` に使えるもの：`composer`（作曲）`arranger`（編曲）`lyricist`（作詞）`vocalist`（歌）`charter`（譜面）`illustrator`（イラスト）

## 本人確認のチェックリスト
- [ ] 作者さんの**公式のアカウント**（Xなど）から、DMや投稿で「このパックを公認してほしい」と連絡があった
- [ ] パックの配布ページが、作者さん本人のものだと確認できた
- [ ] 作者のことば・名前・役割を、`verified.json` に載せてよいと確認した
- [ ] 取り下げたいときの連絡方法を伝えた（Issues か X の DM）

## 権利のチェックリスト（よくあるケース）

> **これは一般的な確認メモで、法的助言やtrk!の公開許可ではありません。** キャラクターの利用条件、楽曲・録音の権利、素材の再配布条件、公開先の受け入れ条件は別々に確認します。本人確認済み・公認済みでも、第三者の権利や公開先の規約まで許諾済みになるわけではありません。trk!でのPCL／東方Projectの適用範囲、公開先のAI生成物の条件、別途制作した5曲の配布条件には未確認事項が残っています。確認が終わるまでは、それらを許諾済みと表示したり、音源を同梱・再配布したりしないでください。

### 初音ミクなど、ボーカロイドの曲
- クリプトン公式の[ピアプロ・キャラクター・ライセンス（PCL）正文](https://piapro.jp/license/pcl)と[要約](https://piapro.jp/license/pcl/summary)は、クリプトンのキャラクターを使った二次創作についての条件です。PCLを、曲・歌詞・編曲・歌唱・録音や第三者のイラストまで一括で使える許可とは扱いません。作詞・作曲・編曲・演奏・歌唱・録音・イラスト等、関係する権利者と各条件を個別に確認してください。
- PCLの対象となるキャラクター表現を使う場合は、本人が作成した二次創作物か、各作者が別途許諾した素材かを確認します。他の人の二次創作物をPCLだけで利用したり、利用者へ再許諾したりはできません。公式の表示例・現行ガイドラインにも従ってください。
- アプリが無料であることだけでは、PCLの全条件、他の素材・楽曲の権利、現在の公開方法への適合が確認できたことにはなりません。公開前に現行の正文と公開先の規約を照合してください。

### 東方Projectのアレンジ曲（例：Bad Apple!!）
- まず[東方Projectの公式二次創作ガイドライン](https://touhou-project.news/guideline/)を確認してください。東方の二次創作である旨の明記、他者の権利を侵害しないこと、公式と誤認させないこと、他の二次創作者の作品を無断で再利用しないこと等が条件です。原作ゲームの素材はスクリーンショット・プレイ動画以外の使用・公開が禁止されています。
- 公式ガイドラインは、二次創作物の頒布先を原作が販売されている流通または許可された流通に限り、ブラウザ／スマートフォンのゲームアプリは無料のもののみとしています。**無料であることだけで、trk!の現在の公開先・配布形態が条件を満たすとは結論しません。** 公開先ごとの受け入れ条件を別途確認してください。
- 既存のアレンジ音源を使う場合、東方Projectのガイドラインだけで、その編曲・演奏・歌唱・録音や音源ファイルの利用／再配布まで許可されるわけではありません。Bad Apple!!等も、曲と特定の録音について権利者・ライセンス・配布条件を個別に確認するまで収録・再配布しないでください。

### 共通
- 公認は「確認した作者本人が、そのパックをtrk!で遊ぶことを認めた」という範囲の表示です。個別の第三者素材・原曲・録音・キャラクター権利や、公開先での配布条件までは自動的に確認済みになりません。権利そのものは各権利者のもので、trk! やGPLの対象にはなりません。
- 収益化はしません（trk! は非営利です）。それでも無料公開を理由に許諾済みとは判断せず、現行の公式条件と配布先規約を確認します。
