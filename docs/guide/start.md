# ゲームをせず、メディアプレーヤーとして使う

> trk! をブラウザで最初に開くまでの流れ。

初めて開くと **「trk!にようこそ！」** が出ます（一度だけ）。音ゲー・再生プレイヤー・動画・書斎（本やテキスト）・インターネットに繋がなくても遊べること、が短く書いてあります。閉じたあとも、**⚙ 設定 → 🛟 緊急復旧 → 👋 ようこそをもう一度** から、いつでも出せます。

← [📚 ガイド目次](index.md)　／　[README](../../README.md)

チュートリアルが不要なら、案内内の **スキップ** を押せます。ゲームを始めずに使う場合は、曲リストの **🎥 基地**（📚 書斎の隣）をタップして（または従来どおりTVドックの **⏻ 電源を長押し**して）メディアプレーヤーへ切り替え、手持ちの曲を読み込んでください。

画面上部の **「← 曲リストに戻る」** を押すとメディアプレーヤーから退出します。**曲はそのまま流れ続けます**（メディアプレーヤーへ入るときと同じで、途切れません。音量だけ選曲中のプレビュー相当に戻ります）ので、曲リストでエフェクトや設定を触っても音が消えません。再生位置は保存されます。止めたいときは、曲名バナーの **⏯** か、メディアプレーヤーの中で一時停止してから退出してください。昔の動き（閉じるたびに止めて、プレビューの開始位置から鳴らし直す）は、⚙ 設定 →「❓ 謎設定（不具合の再現）」の **「🚪 メディアプレイヤーを抜けた時に曲を再読込する」**（初期オフ）で再現できます。内容をスクロールしても、このボタンは上部に残ります。キーボードでは Esc でも退出できます（設定により確認が出ます）。

同梱デモが不要な軽量ビルドを作る場合は、**`assets/optional-demo-audio/` フォルダー全体を削除**してください（MP3は約704 KiB＋手づくり譜面3ファイルで約4 KiB）。`manifest.json` が無くなると、デモ曲とチュートリアルのデモボタンは自動で非表示になります。音源だけ残して譜面を消す（`manifest.json` の `"charts": false`、またはJSONファイルだけを削除）と、デモ曲は全難易度で自動生成になります。メディアプレーヤーや自分の曲の再生には影響しません。すでにブラウザーへ音源が保存されている場合は、容量を完全に空けるためにサイトデータ／Service Worker のキャッシュも消してください。trk's OST Vol.1 のオリジナル曲は trk185 から同梱ではなく、別リポジトリ [music-library](https://github.com/TonbokiriRaikiriMuramasa-Taikoubou/music-library) の Releases から `trk-ost-vol1.stpack` をダウンロードし、設定 → 📦 カスタムパック →「📂 パックを選ぶ」で読み込む形になりました（端末内保存・自動通信なし・CC BY 4.0・譜面は自動生成）。読み込むと「🎓 trk's OST Vol.1」プレイリストにも曲が並びます。

全画面表示では、映像エリアの **左半分を長押しで巻き戻し、右半分を長押しで早送り**できます。約0.45秒で始まり、押している間は少しずつ加速して移動します（再生速度の設定は変わりません）。指を離すと止まり、移動方向と一回の移動秒数が画面中央に出ます。短いタップの再生／一時停止は従来どおりです。

**全画面の拡大・縮小（trk212）：** 映像の上で**マウスホイール**を回すと、**ポインターの位置を中心に**拡大（上）・縮小（下）します。指している場所がそのまま動かないので、見たい所を寄せられます。100%（全体が入る大きさ）から500%までで、**1ホイールあたりの量は 2%／5%（既定）／10%** から選べます（⚙ 設定 → 🎨 見た目 →「全画面の拡大・縮小（ホイール1回）」）。拡大したあとは**ドラッグ（押したまま動かす）**で表示位置を動かせます。タッチ画面では**2本指のピンチ**でも拡大・縮小できます。上部の **🔍 125%** ボタンは今の倍率を表示し、押すと100%に戻ります。ドラッグでの移動は100%より大きいときだけ動くので、100%での左右長押しシークはこれまでどおりです。ドラッグ中は**ポインターを掴む**ので、映像の外（ウィンドウの外）まで動かしてもそのまま続きます。ピンチのあとに1本指を離したときも、**残った指でそのまま動かせます**（置き直しは不要）。

メディアプレーヤーでは、再生キュー、曲送り、リピート、シャッフル、再生速度、前回位置の復元、スリープタイマー、Media Sessionに対応しています。逆再生（対応環境では音声も反転）とA-B区間ループも使えます。**Loop Lab**では、現在位置から5／10／20秒の区間ループ、ランダムな短区間、曲ごとのA-Bプリセット保存・呼び出し・個別削除・全消去ができます。プリセットは曲識別子とA/B秒数だけを端末内に保存し、音源の切り取り・変換・書き出し・アップロードは行いません。動画を一時的に壁紙／スクリーンセーバーで隠すこともでき、時計表示、動画を止める／続ける、トグル／長押し、端末から選んだ画像（セッション中のみ）に対応します。キャストアンテナとバックグラウンド再生アンテナは個別に設定できます。バックグラウンド再生のアンテナはドックの上だけでなく、**右上（言語選択の左）にコンパクトに置く**こともできます（ドックのアンテナを隠しても、バックグラウンド再生は使えます）。キャストは初期オフで、対応ブラウザだけがキャストアンテナから選択画面を開きます（キャストを隠しても、再生用のアンテナは消えません）。アンテナの見た目は、伸縮ロッド／円形ループ／パラボラ／サイバービームの4形状に加えて、**ドットキャラ10体**（🚚トラック・🤖ロボット・🐱ネコ・🫧スライム・👻オバケ、そして東方Projectから⛩霊夢・🧹魔理沙・❄チルノ・🦇フランドール・🗡妖夢）を選べます。キャラは **ONで起きて歩き、OFFで倒れて眠ります**。どれもtrk!の描きおろしで、東方Projectのキャラは二次創作ドット絵です（公式ガイドラインに従い、無料のブラウザゲームとして提供。公式の素材ではありません）。**自分のイラスト2枚**（ON用・OFF用）を選ぶこともでき、画像は端末内にだけ保存されます（設定の初期化で消えます）。

**⏮ 常に最初から再生する（trk193）：** 選曲中のプレビューとメディアプレーヤーの「続きから」を、いつも 0:00 からにしたいときは、この設定をオンにします（初期オフ）。置き場所は3か所—**⚙ 設定 → 🎵 サウンド**の「⏮ 常に最初から再生する」、**メディアプレーヤーのオプション行**の同じチェック、**曲名タブ右上の「⏱ ここをプレビュー開始位置にする」を長押し**すると出る開始位置のバー—で、どれを触っても同じ設定が切り替わります。バーのつまみは0.1秒きざみで開始位置を選べ、動かすとその位置を試せます。「この位置を保存」で曲ごとの開始位置を覚え、「曲の既定に戻す」で解除します。オンの間も、曲ごとの開始位置や保存した再生位置は消えません（オフに戻すと、また使われます）。

**⏱ 「ここをプレビュー開始位置にする」は初期状態では出ていません（trk213）：** 使わない人が誤って触り、その曲の開始位置が変わるのを防ぐため、曲名タブ右上のボタンは**初期オフ**で隠しています。使うときは **⚙ 設定 → 📊 スペクトラム（音の見える化）** の「⏱ 「ここをプレビュー開始位置にする」を表示」をオンにします（ラックの「くわしい設定」にも同じチェックがあります）。オンにすると曲名タブにボタンが出て、押すとその位置を開始位置に保存、長押しで開始位置のバーが開きます。オフに戻すとボタンは消え、開いていたバーも閉じます（曲ごとの開始位置は消えません）。「⏮ 常に最初から再生する」は、このボタンを隠していても **⚙ 設定 → 🎵 サウンド** とメディアプレーヤーから切り替えられます。

**対応している形式：** MP4・MP3・M4A・OGG・OPUS・WAV・WebM・FLAC・AAC・MOV（ブラウザが再生できるもの）
