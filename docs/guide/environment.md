# 💻 動作環境と保存

> 動作環境と、保存されるデータ。

← [📚 ガイド目次](index.md)　／　[README](../../README.md)

最新の **Chrome／Edge** がおすすめです。Firefox・Safari（16.4以降）でも遊べます。

| 機能 | 条件 |
|---|---|
| 📁 ミュージックフォルダを記憶 | パソコンの Chrome／Edge（HTTPS か localhost）。ほかのブラウザでは毎回フォルダを選びます |
| 📤 共有を記憶（🔗 共有をつづける） | パソコンの Chrome／Edge（HTTPS か localhost）。ほかのブラウザでは共有のたびにフォルダを選びます |
| 🧠 解析結果を端末に残す | 自動（同じ曲をもう一度読むと、音の解析を省く。IndexedDB `trk_analysis_cache_v1`。音の波形は残さず、音量などの数値だけ。最大30曲。`?safe=1` では使わない） |
| 💾 共有した曲を端末に残す | 設定でオンにしたときだけ（IndexedDB `shadow_taiko_shared`。最大150曲・300MB。`?safe=1` では読み戻しません） |
| パックの読み込み | `DecompressionStream` に対応したブラウザ |
| 公認パックの確認 | HTTPS か localhost（指紋の計算に必要です） |
| VRM | WebGL。three.js／three-vrm は同梱（`assets/vendor/`）。VRMを使い始めたときだけ読み込みます |
| MMD | WebGL。three.js／three-mmd-loader は同梱（`assets/vendor/`）。MMDを使い始めたときだけ読み込みます |
| ⭐ お気に入り | 端末の中だけ（localStorage）。フォルダ分けも同じ |
| 📚 書斎 | 端末の中だけ（IndexedDB `trk_study_room_v1` の books／pages／covers／settings）。通常の上限は画像アルバム最大3000枚・600MiB・1枚100MiB／文章1ファイル12MiB・一括200ファイル／本棚500冊。栞・メモのコピー・ジャケット・表示設定も同じ場所。`?safe=1` では開きません |

**保存について：** 設定・記録・パック・追加した曲・マイプリセットは、**このブラウザの中だけ**に保存されます（localStorage・IndexedDB）。解析結果（音量などの数値）も同じ場所に残ります。♻️ 初期化では消えません（設定だけが戻ります）。ブラウザのデータを消すと消えるので、記録はときどきバックアップしてください。

設定の **📦 まるごとバックアップ** で、設定・記録・プレイリスト・書斎（本・画像・栞・メモ）・カスタムパックを1つのZIPに書き出せます。曲・VRM・MMDなどの大きいファイルは既定では含まれません（チェックで含められます）。復元は、ZIPを選んで確認したあとに、バックアップに含まれる領域のデータを置き換えます。パックを含まないバックアップでは、既存パックは変更しません。パックは先に導入を試し、導入に失敗した場合も同じIDの既存パックは残します（空き容量が足りずに失敗したときは、不要なパックを削除してからもう一度復元するよう案内します）。完了時にはパックの導入・失敗・削除件数を表示し、IDをすべて確認できず整理を見送った場合も知らせます。内容を確認してダイアログを閉じると再読み込みします。ZIPはこの端末の外へ送られません。

「**容量の上限を無視**」（既定はオフ）が外すのはアプリの保存量上限です。対象は、書斎の本棚500冊・画像アルバム3000枚／600MiB／通常画像1枚100MiB・文章1ファイル12MiB／一括200ファイル、パック1件500MiB・導入済み合計1GiBです。**解除されない安全上限**として、CBZ／ZIPは展開後の1ページ100MiBまで、パックは素材の種類ごとのファイル上限と1パック50曲までを維持します（詳細は[パック形式の仕様](../pack-format.md)）。バックアップZIPにも固定上限があり、最大25万項目・中央目録64MiB、DBのJSONは1ストア64MiB／25万レコードまでです（設定データのJSONは20MiBまで）。作成時にこの固定上限に当たったら、📚書斎などの領域のチェックを外すか、範囲を分けて、小さなバックアップでお試しください。ブラウザや端末の保存容量・メモリ上限も変わらず、足りないときは書き込みに失敗することがあります。大きなデータは分けて取り込み、必要なものをバックアップしてからお試しください。

設定の **💾 端末の保存** に、保存を固定できたかが出ます。書斎の取り込みやパックの取り込みのときに、ブラウザへ「消されにくい保存」を求めます（許可するかはブラウザが決めます。固定されていないときは、大事なものを書き出しで控えてください）。
