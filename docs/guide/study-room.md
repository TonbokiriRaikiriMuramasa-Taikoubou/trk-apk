# 📚 書斎（画像・文章ビューア）

> 📚 書斎（ローカルの画像・文章ビューア）。

← [📚 ガイド目次](index.md)　／　[README](../../README.md)

trk! は音楽ゲームですが、**自分の端末の中身をゆっくり眺める場所**としても使えます。曲リストの見出し（画面左上の「trk! …」）を**長押し**するか、見出しにフォーカスして **Enter／Space** を押すと書斎が開きます。見出しの右の **📚 書斎** ボタンを押しても開けます（このボタンは、設定「長押しの代わりのボタンを出す」をオフにしていても常に出ます）。Escで閉じます。

取り込んだ画像・テキスト・栞・メモ・ジャケットの割り当ては、**IndexedDB `trk_study_room_v1`** に、**この端末の中だけ**保存します（アップロードも通信もしません。元のファイルは変更しません。`?safe=1` では書斎を開かず、保存領域にも触りません）。

- **⚙ 設定**：**書斎上部の「⚙ 設定」は、本を選ぶ前でも、本棚を非表示にしていても開けます。** 読書中は「画像を全画面化」の左側からも、これまでの上級者向け項目（本棚の表示・並び、キー割り当て、拡大の送り幅、マウス操作、取り込み・書き出し先など）を開けます。本棚にも同じ設定への入口があり、本を開いていなくても使えます。変更はすぐ反映・保存され、Esc・「閉じる」・パネルの外側のクリックで読書に戻れます。
- **⛶ 全画面フィット**：設定の一番上にある **「全画面時に強制的に画面にフィットにする」** は初期オフです。オンなら全画面中だけ、画像全体が縦横比を保って画面内に収まります（見開きは左右それぞれ、縦読みは1枚ずつ）。この間は＋／−・0・Ctrl+ホイール・ピンチで拡大率を変更できません。全画面を抜けると元の拡大率に戻り、保存済みの拡大率も変わりません。オフなら従来どおり拡大表示を使えます。
- **🗂 本棚**：画像フォルダは**1フォルダ＝1冊のアルバム**（入れ子フォルダは「フォルダごとに分ける／まとめて1冊」を選べます）、テキストは1ファイル＝1冊として並びます（本棚は最大500冊）。本棚の見出しをクリック／長押しすると整理用フォルダを作成できます。各カードの **⋮⋮** をドラッグして並べ替えたり、フォルダへドロップして本を移動したりできます。タイトル・パス・本文の抜粋で検索でき、**更新が新しい順／追加が古い順／名前順／種類別／大きい順**に並べ替えられます。通常は全画面表示以外で本棚を表示します。⚙ 設定で表示をOFFにしても、ヘッダーの「📚 本棚を表示」から戻せます。⚙ 設定には「並び替えを使わない」（手動配置）、「フォルダを上に表示する」、「削除の時、確認をしない」もあります。栞の付いた本には 🔖 が付き、✎で名前の変更、×で削除（フォルダ削除では本は本棚へ戻ります）。本棚の足元には冊数・画像枚数・使用量（端末の空き容量が取れるブラウザでは空きも）を表示します。
- **📥 取り込み**：進行バーと**中止**ボタン付き。中止しても、すでに入った本はそのまま残ります。同名の本があるときは「中身を置き換える／新しい本として残す」を選べます。大きすぎるファイルなどは理由を表示して飛ばし、最後に「追加・維持・失敗」の件数をまとめて知らせます。
- **📂 フォルダを共有して読む（コピーしない）**：ヘッダーの **📂 フォルダを共有して読む** を押して、画像が入っているフォルダ（書斎のように何千枚あるフォルダでも）を**1回選ぶだけ**。中身は**端末へコピーせず**、ページを開くたびにそのフォルダから読みます（本棚には目次だけが並ぶので、**保存容量が増えません**）。Chromium系（Chrome／Edge）のフォルダー選択に対応した環境で使えます。次回からは同じフォルダを覚えていて、**本を開いたときに許可を1回だけ**確認します（「毎回許可」を選べば以後は出ません）。本棚のカードには **📂（フォルダのまま）** の印が付きます。フォルダの中で画像を移動・削除すると、そのページは「読み込めませんでした」と理由を出します。**元のファイルは変更しません**（読むだけ）。端末を変えたときやバックアップから戻したときは、**同じ名前のフォルダを選び直す**と同じ本として読めます。大量の画像を端末に残したいときは、これまでどおり **🖼 画像フォルダを取り込む**（コピー）を使ってください。
- **🖼 画像**：フォルダを選ぶだけで、中の画像を名前順（数字は数として）に並べます（アルバム最大3000枚・合計600MiB・1ファイル100MiBまで。超えるフォルダは取り込まず、理由を表示します。`jpg/png/webp/gif/avif/bmp`）。並べ方は **1枚ずつ／見開き（右が1ページ目）／縦読み漫画** の3通り、左右と順序を反転する **🇺🇸アメリカン**、読み進める向きを逆にする **画像順の反転**。**画像の左側をタップ／→で次へ、右側／←で前へ**（🇺🇸ではタップ位置を反転）、スワイプでも送れます。**拡大**はボタン・`Ctrl+ホイール`・ピンチ・`+`/`-`/`0` で0.5〜4倍（`0`で100%に戻る）、1回ぶんの幅は⚙ 設定の「拡大の送り幅」で **1／2／5／10／25%** から選べます（初期値5%＝100%→200%が20回）。拡大中はドラッグで見回せます。**拡大した画像は `↑`／`↓` でも送れます**（1回で1画面ぶん、押しっぱなしは少しずつ。端まで来ると、下の「↑ / ↓でページ移動する」設定のページ送りにゆずります）。**倍率に関係なく**、はみ出した画像は `PageDown`／`PageUp` で下端／上端へ一度に飛べます（100%や縮小表示でも使えます）。端でさらにもう一度押すと、**次の／前のページを続きの端から**開きます（`PageDown`＝次のページの上端、`PageUp`＝前のページの下端。**本の端では、閉じる動作**＝画像の全画面を終了して本棚（メニュー）へ戻ります。**「最後のページ時PageDownで本を閉じる」**は初期オンで、オフなら最後の画像の下端で止まり、本も全画面も閉じません（画像の端へ移動する操作が対象。先頭でのPageUpや中クリックの設定は変わりません）。この動きが標準で、⚙ 設定の「PageUP、PageDownをページ動作にする」をオンにすると、画像の端へ移動せず直接ページ送りになります）。キーを**押しっぱなし（キーリピート）にすると画像の端で止まり**、次のページへ移る・閉じるのは押し直したときだけです。画面に収まる画像・縦読み・テキストは従来どおりです。旧設定で端への移動をオフにしていた場合は、直接ページ送りの選択を引き継ぎます。次へ／前へに自分で割り当てたキーは、その割り当てが優先されます。PCのマウス操作の設定（⚙ 設定）もあり、**左右クリックでページを送る**（左＝次へ・右＝前へ。トラックボールや左利き向けの**左右の反転**つき。ページのどこをクリックしても送れます）と、**中クリック**を「何もしない／次のページへ／閉じて本棚へ（全画面を終了）」から選べます（初期値はオフ／何もしない。効くのはマウスのボタンだけで、指のタップはこれまでどおり左右の半分で送ります）。縦読みでは見えているページだけ読み込むので、長い本でも軽いままです。
- **🗜 CBZ／ZIP**：`.cbz`（漫画の書庫）と `.zip` を、ファイル1つ＝1冊として取り込みます（ファイル名が題名）。中の画像だけを名前順のページにし、`__MACOSX` などの Mac の付属ファイルは除きます。通常上限は画像フォルダと同じ（最大3000ページ・合計600MiB・1ページ100MiB）で、超えるものは取り込みません。「容量の上限を無視」をオンにしても、圧縮爆弾対策として **CBZ／ZIP内の1ページ100MiBの展開上限は解除しません**。ZIP構造にも固定上限（1ファイル25万項目・中央目録64MiB）があり、設定では解除されません。壊れたファイルや暗号化されたファイルは「読み込めませんでした」と表示し、ほかのファイルは続けて取り込みます。同じ名前の本があれば、置き換えか残すかを聞きます。
- **📄 文章**：テキストは1ファイルずつでも、フォルダごとでも取り込めます（1ファイル12MiB・一度に200ファイルまで。TXT・MD・JSON・CSV・ログなど）。文字コードは **UTF-8／UTF-16（BOM付き）／Shift_JIS** を自動判定し、青空文庫の `｜《》` ルビも組み立てて表示します。文字スキンは **全24種**（文筆・読書6／コーディング6／AI・プロンプト風5／自由な発想7）。選んだ色・書体・背景は閲覧ページと編集用テキストエリアの両方に適用されます。AI風スキンは見た目だけで、AI処理や通信は行いません。**文字サイズ・行間・余白**をそれぞれ3段階で調整でき（作文用紙は横に流れます）、**本文検索**（`Ctrl+F` か 🔍、`Enter`/`Shift+Enter` で前後の一致へ、見つけた語はハイライト）も使えます。
- **🔖 栞と進捗**：`Enter` 長押しで栞、`M` で**栞一覧**（その位置から開く・外す）。`Space` 長押しで**ページ移動スライダー**（画像）、`Home`/`End` で最初／最後へ。閉じても次のページから開けます。
- **⌨️ キー操作**：初期設定は `→` で次へ、`←` で前へ。⚙ 設定で次へ／前へのキーをそれぞれ割り当て直せます（`↑`／`↓` を画像ページ送りに使う設定もあります）。画像を拡大しているときの `↑`／`↓` は、その拡大した画像を送ります（マウスホイールと同じ場所を動かします）。画像の左右タップ／スワイプは綴じ方向に従います。
- **📜 自動スクロール**：**縦読み漫画モードだけ**。ツールバーの **「⏩ 自動スクロール」** ボタンか `A` キーで、一定の速さで下へスクロールする＝ハンズフリーで読めます。もう一度 `A`・画面の**タップ**・**ホイール**・**移動キー**（`↑` `↓`、`Space`、`Enter`、`PageUp` / `PageDown`、`Home` / `End`、次へ/前へに割り当てたキー）のいずれかで止まります（移動キーはスクロールを止めるだけで、ページは送りません）。**下端（最後のページ）に着くと自分で止まって**知らせます。速さは ⚙ 設定の **「自動スクロールの速度」** で5段階（いちばん遅い／遅い／普通／速い／いちばん速い＝1秒あたり 20 / 45 / 75 / 120 / 180 ピクセル）から選び、**動いている最中の変更もすぐ効きます**。選択は覚えておきます。**全画面（⛶）でも続き**、並べ方の変更・本を閉じる・書斎を出るときは静かに止まります。栞や読んだ位置には触れません。
- **🌗 明るさ/コントラスト（読書用フィルタ）**：⚙ 設定の **「明るさ（読書）」「コントラスト（読書）」** スライダー（50〜150%）と **「特殊フィルタ（読書）」**（なし／反転／グレースケール／セピア）で、読書の見た目を調整できます。**効くのは読書面（画像と文章）だけ**＝本棚・メニュー・TVペインは変わりません。**ドラッグ中にすぐ反映**され、離すと保存されます（リロード後も続きます）。**全画面フィットや拡大率とは独立**なので、どの組み合わせでも使えます。初期値（100% / 100% / なし）ではフィルタ自体がかかりません。
- **❓ キーの説明**：初回に自動で表示され、右上の「❓ キーの説明」か `?` でいつでも再表示できます。
- **✎ テキスト編集と書き出し**：`.txt`／`.md`／`.js` などのテキスト本を開き、「コピーを編集」からすぐ入力できます。入力は自動保存され、`Ctrl`／`⌘+S`で即時保存、`Tab`で字下げ、`Esc`で閲覧に戻ります。編集内容は書斎内のコピーに保存し、元ファイルは変更しません。**JavaScript・HTML・Markdownも常にただの文字列**として扱い、実行・HTML解釈・プレビューはしません。書き出しボタンは閲覧中も使えます。本棚で名前を変えると、書き出しファイル名にも反映されます。⚙ 設定では編集した本の本棚フォルダを指定でき、対応ブラウザなら端末の書き出しフォルダも選べます。選択した端末フォルダへ書き出す場合は元ファイルと別の新規名で保存し、既存ファイルを上書きしません。フォルダ選択は起動中のみ保持し、非対応ブラウザでは通常のダウンロード（同名ファイルの扱いはブラウザ設定）を使います。
- **📺 TVとジャケット**：書斎の中にTV（**上／下／非表示**）を置けます。**見た目は6種**（普通／ブラウン管／木枠／アーケード／プロジェクター／水槽）、**大きさ3段階**、**縦横比**（16:9／4:3／21:9／1:1）、**曲名の表示ON/OFF**。動画を再生しているときはその映像を、音声だけの曲ではジャケットを映します。ジャケットは画像を**長押し（680ms）**するか「🖼 このページを曲のジャケットに」で割り当て、選曲画面の背景・TVドックに反映されます（曲ごとに書斎の中へ保存、同じ操作で消せます）。書斎を閉じる・曲が始まる・曲が変わるときは、動画を**必ず元の場所へ戻します**。
- 書斎を開いている間、ゲーム側のキー操作（モードのキー・スキップ・速度など）は止まります。中断した取り込みで残った読み込み専用の画像は、次に開いたときに自動で掃除されます。
