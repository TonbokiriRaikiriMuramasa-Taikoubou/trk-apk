# assets/mmd/ — 💠 同梱プリセットモデル置き場

ここは「**再配布OKを配布元の規約（れあどめ）原文で確認できた MMD モデルだけ**」を置くフォルダです。
置かれたモデルは、設定 → 🩷 MMDマスコット に **💠 ワンクリックのボタン**として現れます。
（何も置かれていなければボタンは出ず、従来どおり「持ち込み式」のままです）

## ⚠️ ライセンスについて（重要）

- **このフォルダの中のモデル・テクスチャ・れあどめは GPL の対象ではありません。**
  それぞれの配布元の規約（と、初音ミク等のキャラクターについては PCL＝ピアプロ・キャラクター・ライセンス）に従います。
- 同梱できるのは、れあどめ原文に**再配布OK**と書かれているモデルだけです。
  （例：Lat式ミク＝「版権元ガイドラインの範囲内であればデータの改変・流用を含む利用・再配布等オールOK」）
- 同梱するときは **れあどめ原文ファイルを必ず同じフォルダに入れる**こと。
- trk! は非営利・無償です。PCL により商用利用はできません（NOTICE.md 参照）。

## 📁 入れ方（例：lat-miku/）

1. 配布元から入手した zip を展開し、モデル（.pmd/.pmx）・テクスチャ・**れあどめ原文**を
   `assets/mmd/lat-miku/` に入れる
2. `preset.json` を書く（実例：`lat-miku/preset.json`）
3. ブラウザで開くと、設定 → 🩷 MMDマスコット に 💠 ボタンが出る

### preset.json の形

```json
{
  "label": "Lat式ミク",
  "files": ["LatMiku_Normal.pmd", "b.bmp", "f.bmp", "..."],
  "credit": "Lat式ミク / Lat様",
  "motion": "jump",
  "bpm": 130,
  "readme": "Readme_Lat.txt"
}
```

- `files` … このフォルダからの相対パスで**全ファイル**（テクスチャ・toon含む）を列挙。
  **GitHub Pages は大文字小文字を区別**するので、綴りを正確に。
  日本語ファイル名も動きますが、できれば ASCII にリネームしておくと安全です
- `motion` … 読み込み後に自動で始める内蔵モーション（`step` / `swing` / `turn` / `jump` / `idol`）
- `readme` … 規約原文のファイル名（同梱必須。表示はされませんが、配布物として必ず含める）
